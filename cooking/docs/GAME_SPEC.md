# 셰프의 식탁 — 게임 규칙 (v1)

## 1. 하루 흐름
1. **메뉴** 탭에서 식단을 짠다 (코스 3~9접시 / 한식 반상 최대 14가지). 모든 손님이 이 식단을 1인 세트로 먹는다.
2. **식당** 탭에서 가격 배율(권장가의 60~250%)을 정하고 **영업 시작**.
3. 결과: 손님 수, 만족도, 매출 − 재료비 − (임대 20만 + 좌석×3천 + 인건비 = 매출의 30%) = 순이익, 평판 변화, 손님 한마디.
4. 7일마다 **미식 평론가**: (식단 점수 + 실제 완성도)/2 → 76점 ★, 85점 ★★, 93점 ★★★ (별은 오르내림).
5. 7일마다 계절이 바뀜 (봄→여름→가을→겨울). 제철 재료 원가 ×0.8, 제철 아님 ×1.3.
6. 빚이 100만 원을 넘으면 파산.

## 2. 한 그릇의 맛 계산 (flavor.js)
- **맛 7가지**: 단맛·짠맛·신맛·쓴맛·감칠맛 + 매운맛(통증 감각) + 기름진 맛. 0~5.
- 재료 수치를 '부드러운 합'으로 더함: `6 × (1 − Π(1 − 값/6))` → 같은 맛 재료를 많이 넣어도 무한히 세지지 않음. 그 뒤 조리법 수치를 더함.
- **양**: 재료마다 조금(×0.4)·보통(×1)·많이(×1.6). 레시피 데이터에서는 `"salt*0.4"` 처럼 씀.
- **느껴지는 맛**(실제 평가에 쓰임):
  - 억제효과: 쓴맛 −0.25×짠맛 −0.2×단맛, 신맛 −0.2×단맛
  - 매운맛 완화: 매운맛 −0.12×기름 −0.1×단맛 (캡사이신은 지용성)
  - 감칠맛 상승효과: 글루탐산 + (이노신산 또는 구아닐산) 재료가 함께 있으면 감칠맛 ×1.25
  - 대비효과: 디저트에 짠맛 0.2~1.3 이면 단맛 ×1.1 / 차가운 디저트는 단맛 ×0.9
- **완성도(q, 0~100)**: 62점에서 시작해 더하고 뺌. 대표 항목:
  - 식중독(날것·절임에 닭·돼지 등) −45 · 싱거움 −10 · 너무 짬 −15(김치는 4.6까지 허용) · 간이 알맞음 +4 · 단짠 +3
  - 느끼함(기름 3+ 인데 산미·매운맛·알싸한/시트러스/허브/발효 향이 없음) −12 · 산과 지방의 균형 +6
  - 감칠맛 상승효과 +8 · 쓴맛 튐 −10 · 매운 자극 과다 −6 · 밋밋함 −10 · 맛 과다 −8
  - 향 0개 −6 · 2~4개 +4 · 7개 이상 −6 · 질감 2가지 이상 +3
  - 좋은 짝(최대 3개) 각 +5 · 나쁜 짝 각 −9 · 제철 +4 / 제철 아님 −4 · 정통 레시피 +6
  - 디저트: 단맛 부족 −15, 짬 −14, 소금 한 꼬집(대비효과) +5 / 입가심: 차갑거나 새콤 +8
- **무게감(1~5)**: 기름·고기 종류·탄수화물·조리법으로 계산. 코스 흐름 평가에 씀.
- **실제 완성도** = q × 셰프 숙련도(그 조리법 Lv0 80% ~ Lv5 100%). 영업한 손님 수만큼 경험치, Lv = √(경험치/30).

## 3. 식단 평가 (menu.js)
총점 = 항목 점수의 가중 평균 − 지적(✗) 1개당 1.5점. 등급 S 92+ / A 82+ / B 70+ / C 55+ / D.
**완벽한 식단** = S등급 + 지적 0개.

## 4. 손님 (customers.json)
- 하루 손님 = (10 + 평판/25 + 별×8) × (0.6 + 식단점수×0.006) × 가격 영향(1.3 − 0.3×배율) × 날마다 0.85~1.15 × 주말(6·7일째) 1.25, 최대 좌석×2.
- 만족도 = 실제 완성도×(0.55 − 0.3×메뉴민감도) + 식단 점수×(0.15 + 0.3×메뉴민감도) + 취향 점수×0.3 ± 6.
- 받아들이는 가격 = 권장가 × (0.55 + 만족도×0.009) × 지갑 × (1 + 0.12×별). 넘으면 만족도 감소, 25% 이상 싸면 +4.
- 채식주의자: 채식 요리가 하나도 없으면 돌아감(평판 −1), 일부면 비율만큼 감점.
- 평판 변화 = Σ(만족도 − 65)×0.05 (미식가 ×2) + 평론가 (점수 − 70)×1.5. 0~1000.
- 손님 종류(등장 평판): 동네 주민·직장인·가족·어르신(0), 매운맛 마니아(30), 연인(50), 건강식(60), 채식(80), 관광객(120), 미식가(200).

## 5. 연구실 (레시피 수집)
- 조리법 1개 + 재료 1~8개(첫 번째가 주재료). 실험할 때마다 재료비가 듦.
- 같은 조리법이고 레시피 재료를 **모두** 포함하며 남는 재료가 1개 이하이면 → 그 레시피 발견 (양은 상관없음).
- 아니면 **창작 요리**로 저장(최대 40개) — 메뉴에 넣을 수 있음(정통 보너스 없음).
- 힌트: 모르는 레시피 중 가장 비슷한 것의 문화권·부족한 재료 수·종류·조리법이 다른지 알려 줌.
- 매일 **소문**: 모르는 레시피 하나의 이름·조리법·주재료.
- 레시피 얻는 곳: 처음부터 26개 / 요리책 16권 / 연구실에서만(숨은 레시피 18개).
