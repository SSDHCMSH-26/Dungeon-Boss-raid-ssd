# 픽셀 던전 레이드 — 인수인계 문서 (README)

> 새 대화나 새 프로젝트에서 이어서 작업할 때 **이 파일부터** 읽게 하세요.
> 마지막 정리 시점: 2026-10-10 · 최신 빌드 **v58** (`boss-raid-v58.html`)

## 1. 한 줄 요약
30×30 칸 던전에서 **보스 1명(그론 / 빈센토) vs 용사 3명(기사·성직자·궁수·마법사 중 선택)** 이 턴제로 싸우는 단일 HTML 게임.
혼자 하기(컴퓨터 상대) · 한 기기 테스트 · 두 기기 온라인(Claude 아티팩트 `db` 사용) 모드가 있음.

## 3. 새 대화에서 이어가는 방법
1. 새 대화(또는 새 프로젝트)에 `boss-raid-v58.html` 과 위 `.md` 파일들을 첨부.
2. 첫 메시지 예시:
   > "첨부한 README_HANDOFF.md 를 먼저 읽고, GAME_SPEC.md 와 CODE_MAP.md 를 기준으로 이어서 작업해줘. 수정은 변경 부분만 고치고 3줄 요약해줘. 끝나면 같은 아티팩트 링크에 게시해줘."
3. 코드 파일의 **99% 가 이미지(base64)** 이므로 통째로 읽히지 말고, 필요한 함수만 찾아 읽게 하면 토큰이 크게 절약됩니다 (CODE_MAP.md 의 함수 목록 참고).

## 4. 작업 방식 (지금까지 유지한 규칙)
- 단일 `index.html`, 외부 의존성 없음 (폰트만 Google Fonts).
- 수정은 **패치 방식**(원본 문자열을 찾아 교체)으로 하고 `assert` 로 한 곳만 바뀌는지 확인 → 문법 검사(`node --check`) → Playwright 로 규칙 테스트/스크린샷 → 게시.
- 규칙을 바꾸면 컴퓨터끼리 대전(`tools/sim.py`)으로 밸런스를 돌려보고 결과를 보고.
- 기존 디자인 3종(기존 디자인 / 테마 2 / 테마 3) 선택 기능은 유지.
- 게시: Claude `Artifact` 도구로 **같은 URL** 에 게시. (이 문서 작성 시점 링크: https://claude.ai/artifact/M6mPmXnyaqVsT4E9RdeDFd — 계정 소유자만 갱신 가능)
- 메모리: 요청 사항은 `areas/web-game-project.md` 에 [stated] 로 누적 기록됨.

## 5. 알려진 한계 / 확인이 필요한 점
- 컴퓨터 용사는 성직자 궁극기·방패돌진·순간이동을 쓰지 않음 → 밸런스 시뮬 수치는 **참고용**(특히 빈센토전은 용사 열세로 나옴: 용사 승 1~7 / 60판).
- 온라인 모드는 상태 전체를 양쪽 기기에 동기화하므로 **함정·폭탄 위치가 개발자 도구로 보임** (공개 서비스 전 서버 판정으로 이전 필요 → ONLINE_PLAN.md).
- 미믹·보물 고블린은 별도 디자인이 없고 모든 디자인에서 같은 그림 사용.
- 보물 고블린: 체력 30, 금화 강탈량 3~7은 임의로 정한 값. 아이템 강탈 성공 시 AP 환급이라 한 턴에 연속 강탈 가능(필요 시 횟수 제한).
- 미믹 제압은 "2턴/3턴" 표현이 섞여 있어 **3턴**으로 구현. 확인 필요.
- 마력 방출의 "전체 10 피해"는 설치 벽에는 들어가지만 **맵 기본 벽에는 들어가지 않음**(미로 붕괴 방지). 기본 벽은 3칸 이내(50 피해)만 파괴.
- 이미지는 사용자 제공 컨셉 시트에서 잘라 쓴 것 → 상업 출시 전 사용 권한 확인 필요.
- 아직 미구현 챔피언: 테르나, 온, 파라오 (디자인 선택창만 있음).
