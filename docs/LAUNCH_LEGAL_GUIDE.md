# 런칭·배포·법률 가이드 (한국 기준, 비개발자용)

> ⚠️ 이 문서는 법률 자문이 아닙니다. 법·제도는 자주 바뀌므로 **각 단계 실행 직전에 공식 사이트(게임물관리위원회, 국세청, 개인정보보호위원회, Steam)에서 최신 내용을 확인**하세요. 불확실한 부분은 "확인 필요"로 표시했습니다. 금액이 걸리는 단계 전에는 변리사/변호사/세무사 1회 상담(약 10~30만 원대)을 권장합니다.

## 0. 한눈에 보는 순서
| 단계 | 언제 | 하는 일 | 누가 |
|---|---|---|---|
| 1 | 지금~개발 중 | 에셋(그림·소리·폰트) 출처/라이선스 기록 | 나 + Claude |
| 2 | 베타 전 | 수익 모델 결정 (무료/유료/인앱결제/확률형 여부) | 나 |
| 3 | 베타 전 | 개인정보처리방침·이용약관 작성 | Claude 초안 + 전문가 검토 |
| 4 | 공개 전 | 사업자 등록(개인사업자), 통신판매업 신고(판매 시) | 나 (세무서/구청) |
| 5 | 공개 전 | 게임물 등급분류 (게임물관리위원회 또는 자체등급분류 사업자) | 나 |
| 6 | 공개 전 | 플랫폼 입점: 웹 호스팅 / Steam / 모바일 | 나 |
| 7 | 공개 후 | 세금 신고, 운영(CS, 환불, 신고 대응), 업데이트 | 나 |

## 1. 에셋(그림/소리) 저작권 — 가장 먼저, 가장 싸게 막을 수 있는 위험
- 지금 게임에 쓰인 스프라이트·타일 이미지가 **직접 만든 것인지, 구매/무료 라이선스인지, AI 생성인지** 목록으로 정리합니다 (`ASSET_LOG.md` 같은 표: 파일명 / 출처 / 라이선스 / 상업 이용 가능 여부).
- 상업 출시(유료·광고·인앱결제)면 **상업 이용 가능 라이선스**만 사용. "비상업 전용", 출처 불명 이미지는 교체 대상.
- AI 생성 이미지는 플랫폼마다 규정이 다릅니다. Steam은 AI 사용 여부를 입점 시 공개해야 합니다 (확인 필요: 최신 규정).
- 기존 유명 게임의 캐릭터/UI를 닮게 만들지 않기.

## 2. 수익 모델 결정 (법적 부담이 크게 달라짐)
- **완전 무료 + 광고 없음**: 법적 부담 가장 작음. 등급분류·개인정보는 여전히 필요할 수 있음.
- **패키지 유료(Steam 등)**: 사업자 등록·세금 필요.
- **인앱결제/아이템 판매**: 전자상거래법(청약철회, 환불), 통신판매업 신고, 미성년자 결제 제한 필요.
- **확률형 아이템(가챠/랜덤 박스)**: 한국은 확률 정보 공개 의무가 있습니다(2024년 시행, 위반 시 제재). **랭킹 PvP 게임이라면 돈으로 강해지는 구조 자체를 피하는 것이 공정성 면에서도 가장 안전**합니다 → 추천: 코스메틱(외형)만 판매, 확률형 없음.
- 현금화 가능한 보상/내기성 요소는 사행성 문제로 금지 수준이니 **절대 넣지 않기**.

## 3. 개인정보·약관 (계정/랭킹이 생기면 필수)
계정, 이메일, 접속기록, 결제정보를 다루면 개인정보보호법 적용 대상입니다.
1. **수집 최소화**: 이메일 또는 소셜 로그인 + 닉네임 정도만. 주민번호·실명은 받지 않기.
2. **개인정보처리방침** 작성·공개 (수집 항목, 목적, 보관 기간, 제3자 제공/위탁 — 서버 호스팅·결제 대행사 포함).
3. **이용약관**: 계정 정지 기준, 환불, 서비스 종료 시 처리, 부정행위(핵/매크로/계정 거래) 금지.
4. **14세 미만**: 법정대리인 동의가 필요 → 가장 쉬운 방법은 "만 14세 이상 가입"으로 제한하되, 등급과 모순되지 않게 설정 (확인 필요).
5. 서버를 해외(AWS 등)에 두면 **국외 이전 고지** 필요. 유럽 이용자를 받으면 GDPR 고려 (확인 필요).
6. 비밀번호는 직접 저장하지 말고 검증된 인증 서비스(Firebase Auth, Supabase 등) 사용 → 보안 사고 위험 대폭 감소.
7. 유출 사고 대응 절차(신고 의무)를 미리 한 장 문서로 준비.

## 4. 사업자 등록·세금
- 돈을 벌 계획이 있으면 **개인사업자 등록**(세무서, 온라인 홈택스 가능). 업종은 소프트웨어 개발/게임 소프트웨어 관련 (세무서 안내 따르기).
- **간이과세 vs 일반과세**: 매출 규모에 따라 달라짐. 세무사 상담 권장.
- 온라인에서 이용자에게 판매하면 **통신판매업 신고**(구청, 일부 면제 요건 있음 — 확인 필요).
- 해외 플랫폼(Steam) 수익은 해외 원천징수·부가세 처리가 있어 **세무사 1회 상담** 권장.
- 수입은 종합소득세(5월) 신고. 지출 영수증(서버비, 툴 구독, 에셋 구입)을 모아두면 비용처리 가능.
- 부업이 직장 규정에 걸리지 않는지 확인 (겸업 금지 조항).

## 5. 게임물 등급분류 (한국 서비스 시)
- 한국에서 게임을 서비스하려면 원칙적으로 **등급분류**가 필요합니다. 방법은 두 갈래:
  - **게임물관리위원회(GRAC)** 심의.
  - **구글/애플 등 오픈마켓 자체등급분류 사업자**를 통한 모바일 게임 등급 (확인 필요: 현재 대상과 절차).
- 준비물: 게임 설명, 플레이 영상/빌드, 폭력성·선정성·사행성·언어 등 항목 답변. 이 게임은 폭력 표현이 도트 수준이라 낮은 연령 등급이 예상되지만 **실제 판정은 심의 결과** 에 따릅니다.
- 등급 표시(마크)를 게임 화면/스토어 페이지에 표기해야 합니다.
- 베타 테스트라도 일반 공개면 등급 문제가 될 수 있으므로, **공개 전 GRAC 사이트에서 대상 여부 확인**.
- Steam 글로벌 판매는 Steam 자체 연령 설문(콘텐츠 설문)을 작성하며, 한국 이용자 대상 별도 요건은 최신 안내 확인 필요.

## 6. 플랫폼별 배포
### 6-1. 웹 (가장 쉬움, 먼저 시작 추천)
- 정적 호스팅(Cloudflare Pages / Netlify / GitHub Pages) → 무료로 시작 가능. 도메인은 연 1~2만 원대.
- 온라인 대전·랭킹은 **별도 서버**(로그인, 매칭, 결과 검증)가 필요 → 월 몇 천 원~수만 원대로 시작, 이용자가 늘면 증가.
- 사용자가 코드를 볼 수 있다는 점 때문에 **판정은 항상 서버가** (ONLINE_PLAN.md 참고).

### 6-2. Steam
- **Steam Direct**: 앱당 등록비(약 $100, 확인 필요), 일정 매출 달성 시 환급되는 구조. 입점 절차: 개발사 계정 → 세금/은행 정보 → 앱 등록 → 스토어 페이지(캡처, 설명, 트레일러) → 빌드 업로드 → 심사 → 출시일 설정.
- 스토어 페이지는 출시 **최소 2주 전**에 공개해야 하고, 찜(위시리스트) 모으기가 흥행에 중요.
- 웹 게임을 Steam용으로 쓰려면 **Electron/Tauri로 포장 + Steamworks SDK** 연동(로그인, 업적). 이 작업은 로컬 Claude Code로 진행 추천.
- AI 사용 공개, 등급/콘텐츠 설문 필요.

### 6-3. 모바일 (Google Play / App Store)
- Google Play 개발자 등록 약 $25(1회), Apple Developer 연 $99 (확인 필요).
- 웹 게임을 앱으로 포장(Capacitor 등) 가능. 앱 심사·결제 수수료(약 15~30%) 존재.
- 토스 앱인토스 등 국내 플랫폼 입점도 가능 — 별도 등급/심사 규정 존재 (확인 필요).

## 7. 공정성·운영 관련 법/정책
- **부정행위(핵/매크로)**: 약관에 금지·제재 규정 명시. 서버 판정으로 근본 차단.
- **계정 거래/대리 랭킹 올리기**: 약관 금지.
- **신고·차단·닉네임 필터**: 욕설 닉네임 필터, 신고 기능 최소 구현.
- **서비스 종료 시**: 사전 공지(보통 30일 이상 권장), 유료 결제분 환불/처리 방침을 약관에 미리 명시.
- **청소년 보호**: 심야 결제/이용 제한은 현재 법 상황 확인 필요.
