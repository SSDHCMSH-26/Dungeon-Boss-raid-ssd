# Firebase JS SDK (compat) 10.12.2

"둘이서 하기"(두 기기 온라인) 서버 연결용. npm `firebase@10.12.2` 패키지의 `firebase-app-compat.js`, `firebase-auth-compat.js`, `firebase-firestore-compat.js` 를 그대로 복사.
CDN 없이 게임 폴더 안에서 불러오며, 둘이서 하기를 누를 때만 읽음(`game/src/net/net.js` 의 `fbNet`).
