# game/data — 게임 수치 파일 (v62~)

여기 있는 JSON 파일의 숫자를 바꾸면 게임 코드를 건드리지 않고 수치를 바꿀 수 있습니다.
- 수정 후에는 꼭 확인: `python3 tools/compare_versions.py <이전 game 폴더>` → 바꾼 부분만 달라지는지 확인(바꾼 만큼 FAIL 이 나오는 게 정상).
- JSON 규칙: 마지막 항목 뒤에 쉼표 금지, 글자는 큰따옴표("…"), 주석 불가. 틀리면 게임 첫 화면에 "게임 데이터를 불러오지 못했어요" 가 뜹니다.
- 설명 문구(`sm`, `d`, `pas`)는 **글자 그대로** 표시됩니다. 숫자(`v` 등)를 바꾸면 설명 문구 속 숫자도 직접 같이 고치세요.
  (단, `monsters.json` 의 수치는 상자 개봉 메시지·몬스터 정보 창 문구에 자동 반영됨)
- `index.html` 을 파일로 직접 열면 데이터를 못 읽습니다 → GitHub Pages 주소나 `python3 -m http.server` 로 여세요.

## heroes.json — 용사 기본 수치
| 키 | 뜻 |
|---|---|
| `n` | 이름 |
| `hp` | 최대 체력 |
| `mv` | 기본 이동 칸 수 |
| `pas` | 패시브 설명(성직자). 실제 효과는 코드에 있음 |
용사 순서(knight, cleric, archer, mage)는 선택 화면 순서입니다.

## skills.json — 스킬
`heroes` = 용사별 스킬 목록(순서 = 스킬 버튼 순서, **순서를 바꾸면 안 됨**: 코드가 번호로 부름).
`champions` = 보스별 `at`(공격 예고), `ex`(설치·특수), `gx`(빈센토 발전기 스킬).
| 키 | 뜻 |
|---|---|
| `n` | 이름 |
| `c` | AP 비용 |
| `r` | 사거리 |
| `a` | 범위(0=1칸, 1=3×3 …) |
| `t` | 종류(코드가 쓰는 기호: d 피해, h 치유, g 방패막기, l 성광, u 계시, r 돌진, b 순간이동, o 마력 방출) — **바꾸지 말 것** |
| `v` | 피해/회복량 |
| `cd` | 쿨타임(턴) |
| `sm` / `d` | 짧은 설명 / 자세한 설명 |
| 보스 `id` | 코드가 쓰는 기호 — **바꾸지 말 것** |
| 보스 `pk` | 찍어야 하는 칸 수, `sh` 모양(sq 사각, cross 십자), `k` 크기, `lim` 턴당 사용 횟수, `dg` 대각선 포함, `par` 마비, `vr`·`esc` 특수 규칙 |

## monsters.json — 미믹·보물 고블린
| 키 | 뜻 |
|---|---|
| `mimic.hp` | 미믹 체력 |
| `mimic.move` | 깨어난 뒤 턴당 이동 칸 |
| `mimic.bite` | 인접 용사 공격 피해 |
| `mimic.suppressTurns` / `suppressDmg` | 상자를 연 용사 제압 턴 수 / 턴마다 피해 |
| `gob.hp` | 고블린 체력 |
| `gob.ap` | 턴당 AP(훔치기 1회 = AP 1) |
| `gob.move` | 한 번 이동할 때 최대 칸 |
| `gob.steal` | 훔치기 피해 |
| `gob.goldChance` / `itemChance` | 금화 강탈 확률 / 아이템 강탈 확률 (나머지 = 실패). 0.6 = 60% |
| `gob.goldMin` / `goldMax` | 금화 강탈량 범위 |
| `trapChest.mimicChance` | 함정 상자에서 미믹이 나올 확률(나머지는 고블린) |
