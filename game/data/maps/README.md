# 맵 파일 형식 (pdr-map, version 1)

맵 하나 = 파일 하나. 맵 편집기·공용 맵 공유·스토리 스테이지가 모두 이 형식을 씁니다.
검사 코드: `game/lib/validate.js` 의 `map()` / `mapText()` — 게임은 맵을 쓰기 전에 **반드시** 이 검사를 통과시킵니다(남이 만든 맵은 믿지 않음).

## 파일 목록 — `index.json`
```json
{ "format": "pdr-map-index", "version": 1,
  "maps": ["gron_maze", "vince_factory"],
  "default": { "gron": "gron_maze", "vince": "vince_factory" } }
```
- `maps`: 게임이 불러올 맵 ID 목록 → 각각 `data/maps/<ID>.json`
- `default`: 챔피언별 기본 맵 (챔피언 ID → 맵 ID)

## 맵 파일 — 예: `vince_factory.json`
| 항목 | 필수 | 뜻 |
|---|---|---|
| `format` | ✅ | `"pdr-map"` |
| `version` | ✅ | 형식 버전. 지금 `1`. 게임보다 새 버전이면 거부 |
| `id` | ✅ | 맵 이름표. 영어 소문자·숫자·`_`·`-` 1~64자, **파일 이름과 같아야 함** |
| `name` | ✅ | 화면에 보일 이름 (1~40자) |
| `author` | | 만든 사람 (40자 이하). 공식 맵은 `"official"` |
| `champion` | ✅ | 이 맵의 보스 (champions.json 의 공개된 챔피언 ID) |
| `ruleset` | ✅ | 규칙 묶음 ID (지금은 `"standard"` 하나). **수치(피해·체력)는 맵에 넣지 않음** |
| `size` | ✅ | `{ "w": 30, "h": 30 }` — v1 은 30×30 만 |
| `tiles` | 둘 중 하나 | 지도. 30줄 × 30글자, `.` 바닥 / `#` 벽. 위에서부터 y=0, 왼쪽부터 x=0 |
| `generator` | 둘 중 하나 | 자동 생성. `{ "type": "maze" }` = 그론 랜덤 미로(매 판 바뀜) |
| `spawns` | ✅ | 시작 위치 (아래) |
| `objects` | | 미리 놓는 물건 목록 (아래) |
- 모르는 항목(오타 포함)이 있으면 거부합니다.

### spawns — 시작 위치
- `boss`: `{x, y}` — 보스는 3×3 이라 **가운데 칸**. 가장자리에서 1칸 이상 안쪽, 3×3 안에 벽 없어야 함
- `generator`: 발전기가 있는 챔피언(빈센토)만, 보스와 같은 규칙, 보스와 겹치면 안 됨
- `heroes`: 용사 3명 `[{x,y}, {x,y}, {x,y}]` — 바닥, 서로 다른 칸
- **길 확인**: 용사마다 벽을 부수지 않고(8방향 걷기) 보스 바로 옆까지 갈 수 있어야 함 (`tiles` 맵만)

### objects — 미리 놓는 물건 (디펜스 모드·편집기용)
| type | 크기 | 뜻 |
|---|---|---|
| `chest` | 1칸 | 보물상자 |
| `trapChest` | 1칸 | 함정 상자 (미믹/고블린) |
| `pit` | 2×2 (x,y 가 왼쪽 위) | 숨은 구덩이 |
- 바닥 위, 맵 안, 시작 위치·다른 물건과 겹치지 않기
- 개수 한도: 상자(chest+trapChest) ≤ 규칙 묶음 `chest.max`, 구덩이 ≤ 구덩이 스킬 `fx.max`, 전체 200개 이하

### 공유 맵 안전장치
- 파일 크기 64KB 이하, JSON 형식 확인 → 위 검사 전부 → 통과해야 사용
- 맵에는 수치가 없으므로 맵 공유로 피해량·체력을 조작할 수 없음
- 랭크전에서는 맵 ID·규칙 묶음 ID·데이터 버전을 양쪽이 확인 (나중 단계)

## 버전을 올릴 때 (개발용)
형식이 바뀌면 `validate.js` 의 `MAP.version` 을 올리고, 옛 버전 맵을 새 형식으로 바꾸는 변환을 `map()` 앞에 추가합니다. 옛 맵 파일은 그대로 두어도 열려야 합니다.
