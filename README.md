# Dungeon Boss Raid

턴제 1대1 보스 레이드 게임 (단일 HTML). 장기 목표는 `docs/VISION_ROADMAP.md` 참고.

- 플레이 주소: https://ssdhcmsh-26.github.io/Dungeon-Boss-raid-ssd/ (설정: `docs/DEPLOY_PAGES.md`)
- `game/index.html` : 현재 게임 코드 (v64)
- `game/data/` : 용사·스킬·몬스터 수치 JSON (설명: `game/data/README.md`)
- `game/art/` : 게임 그림 파일 (index.html 과 함께 있어야 함)
- `docs/` : 기획·인수인계·코드지도·온라인계획·런칭/법률 가이드
- `tools/` : 테스트·시뮬레이션 예시 스크립트
- `data/` : (예정) 영웅·스킬·몬스터·스테이지 수치 JSON
